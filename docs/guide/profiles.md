# Профили, роли и подарки

Новое в 1.8.4: у каждого игрока есть профиль — как в Telegram.

## Открыть профиль

- **ПКМ по сообщению → «Профиль игрока»** — самый универсальный способ:
  работает в личке, общем чате, каналах и группах и открывает профиль **автора
  этого сообщения** (новое в 1.10.1), **или**
- **ПКМ** по диалогу в списке слева, **или**
- кнопка **«☺»** в шапке открытого личного диалога, **или**
- меню **«⋮» → «Профиль»**.

::: tip Профиль — только у игроков
У публичного канала, группы, общего чата и ленты CoreProtect профиля нет —
кнопки профиля там не будет. Раньше такая вкладка молча открывала **ваш
собственный** профиль.
:::

## Что показывает профиль

- **Полный ник с префиксом и суффиксом** — так, как игрок выглядит на сервере
  (роль, клан, донат-тег и т.п.). Ник берётся из списка игроков (таб).
- **Аватар** (скин), статус **в сети / не в сети**.
- **День рождения** и **описание** — их можно задать в своём профиле («Мой
  профиль»).
- **Баланс** — только в своём профиле, рядом с ником (нужен серверный плагин +
  Vault).

## Должность определяется автоматически

Роль-должность **не выставляется вручную** — она определяется из ника
(префикс/суффикс). Если в нике есть один из значков или слов, рядом с ником
появляется бейдж:

| Значок | Должность |
|:---:|---|
| Ⓒ | Контент-мейкер |
| Ⓗ | Хелпер |
| Ⓜ | Модератор |
| Ⓔ | Ивент-мейкер |
| Ⓓ | Разработчик |

Также распознаются слова: `helper`/`хелпер`, `moder`/`модер`,
`developer`/`разраб`, `event`/`ивент`, `content`/`контент`.

## Личные заметки

Как в Discord: в профиле любого игрока есть поле **«Заметка»** — короткая
запись для себя (например, «продал зачарованную кирку за 5 алмазов»).

::: tip Заметка видна только вам
Заметка нигде не публикуется и никуда не отправляется — она хранится только у
вас на компьютере, в `pmchat.json`. Собеседник о ней не узнает, даже если у
него тоже стоит PocketChat.
:::

## Переименовать игрока

В профиле любого игрока есть поле **«Имя»**. Впишите туда своё имя — и игрок
будет отображаться под ним в списке переписок и в шапке диалога (реальный ник
остаётся в заголовке профиля). При переименовании игрок добавляется в
**контакты**. Чтобы убрать переименование, очистите поле.

По умолчанию переименование только для отображения — команды `/m` уходят по
настоящему нику. Если на вашем сервере к игроку обращаются по отображаемому
имени, включите в настройках **«/m по переименованию»** — тогда `/m` будет
уходить на заданное имя.

## Чёрный список

В профиле игрока есть кнопка **«В чёрный список»**:

- у заблокированного **скрывается аватарка** (даже когда он онлайн);
- в шапке диалога появляется значок **«⊘ ЧС»**;
- без серверного плагина блокировка дублируется в Essentials командой
  `/ignore`.

Убрать из ЧС — той же кнопкой в профиле.

## Пожаловаться на игрока

Рядом с «В чёрный список» — кнопка **«Пожаловаться»**: короткая причина уходит
на бэкенд PocketChat и видна только админу сервера (см. «Правила PocketChat»
при первом запуске мода — угрозы и травля запрещены). Нужен аккаунт бэкенда
(вкладка «Аккаунт» в настройках).

## Поддержка

В настройках, вкладка **«Аккаунт»**, есть кнопка **«Поддержка»** — короткое
сообщение уходит тому же админу, что и жалобы.

## Модерация: мут и бан

Админ сервера может замутить игрока (временно, на N минут) или забанить его
(насовсем) через админ-панель. У замученного/забаненного блокируется отправка
текста, голосовых и фото — при попытке проигрывается анимация отказа (✋) и
надпись «У вас нет прав». Работает только для игроков со своим аккаунтом
бэкенда (вход через «Аккаунт» в настройках) — обычный `/m` бэкенд не видит, так
что мут/бан применяется на стороне клиента при следующей проверке статуса
(до минуты задержки).

## Подарки за монеты (Vault)

Раздел **«Подарки»** работает, когда на сервере стоит плагин **PocketChat** +
**Vault** и экономика (например EssentialsX).

- Откройте профиль **другого** игрока → раздел «Подарки» → **клик по подарку**.
- Цена спишется с вашего баланса Vault, получателю придёт уведомление.
- Полученные подарки видны в профиле игрока.
- Каталог подарков настраивается в `config.yml` плагина (секция `gifts:`).

Без плагина раздел показывает «доступно с плагином».

## Стримы + донаты (Vault)

Значок камеры внизу мессенджера открывает список игроков, которые сейчас
стримят на внешнем сервисе (Twitch/YouTube — мод не транслирует видео сам,
только показывает статус и ссылку):

- **«Начать стрим»** — название + ссылка, видно всем онлайн с плагином;
- **Донат** — рядом с именем стримера, монеты Vault списываются с вашего
  баланса и зачисляются стримеру.

Список стримов и донаты доступны только при серверном плагине **PocketChat**
+ **Vault** и экономике — без плагина раздел показывает «нужен плагин».

## Темы интерфейса

В настройках добавлены новые темы (тёмные и светлые): **Полночь**, **Nord**,
**Роза**, **Песок** — в дополнение к прежним Тёмной, Светлой и Графит.

## Аватарки групп

Групповому чату можно поставить свою картинку: положите изображение в
`config/pmchat-avatars/` и нажмите на аватарку в шапке группы — она будет
перебирать доступные файлы.
