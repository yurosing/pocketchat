## PocketChat 1.11.0

Публичный **API** для разработчиков — и к серверному плагину, и к клиентскому
моду. Обе библиотеки лежат на Maven Central. В комплекте — мод и **бесплатный**
серверный плагин PocketChat.

### 🧩 Новое: API

Другие плагины и моды теперь могут встраиваться в PocketChat, а не парсить чат.

```groovy
repositories { mavenCentral() }

dependencies {
    compileOnly 'io.github.yurosing:pocketchat-api-plugin:1.0.0'   // плагин Paper
    modCompileOnly 'io.github.yurosing:pocketchat-api-mod:1.0.0'   // мод Fabric
}
```

**API плагина** (`com.pmchat.api`) — восемь событий Bukkit, четыре из них
отменяемые, плюс сервис `PocketChatApi`:

- **ЛС** — `PocketChatMessageEvent`: перехват и отмена личных сообщений, доступ
  к обеим формам (структурной и текстовой), правка текстовой. Отдельно
  `PocketChatMessageOfflineEvent` — можно забрать доставку оффлайн-сообщений себе.
- **Медиа** — `PocketChatMediaUploadEvent` / `…DownloadEvent`: первые в плагине
  права на отправку и скачивание файлов, свои лимиты по размеру и по рангу.
- **Подарки** — `PocketChatGiftPurchaseEvent`: скидки, ограничения, отмена
  покупки **до** списания через Vault. `GiftRegistry` — свои подарки в каталоге,
  `giveGift(...)` — выдать бесплатно за ивент.
- **Сервис** — отправка ЛС от имени игрока и от имени сервера, список игроков с
  модом, баланс, прямой доступ к хранилищу медиа.
- API ищется через сервис-менеджер Bukkit, поэтому одинаково работает и на
  `PocketChat`, и на `PocketChatPro`.

**API мода** (`com.pmchat.api.client`) — без единого класса Minecraft внутри, так
что не ломается при смене версии игры:

- слушатель на входящие и исходящие сообщения, подарки, открытие переписки и
  смену издания плагина на сервере;
- **вето** на исходящие — `allowOutgoing(...)`;
- чтение списка переписок и истории, отправка сообщений, открытие окна
  мессенджера, всплывашки, чёрный список.

Опкоды протокола `pmchat:media` теперь тоже опубликованы — класс
`PocketChatProtocol`, для тех, кто пишет прокси или мост.

### 🔧 Под капотом

- Опкоды протокола больше не дублируются в плагине — единственный источник
  правды теперь в API-модуле.
- Каталог подарков в плагине стал изменяемым, полученные подарки отдаются
  типизированной записью вместо `String[]`.

### 📦 В комплекте

- `pmchat-mod-1.11.0.jar` — клиентский мод (в папку `mods/`).
- `PocketChat-2.0.0.jar` — бесплатный серверный плагин (в папку `plugins/`).
  Нужен для медиа-релея, баланса и подарков (+ Vault и экономика вроде
  EssentialsX для подарков/баланса).

Классы API уже внутри обоих jar-ов — подключайте их только как `compileOnly`.

### 🔒 Чем отличается от приватной (secret) сборки

Публичная версия **не включает Pro-плагин** (`PocketChatPro`) и его премиум-
функцию:

- **Расшифровка голосовых сообщений в текст** — работает только с Pro-плагином,
  которого в публичной версии нет. В меню голосового пункт остаётся, но
  подписан «только Pro-плагин».

Всё остальное — профили, подарки, ЧС, темы, медиа-релей, звонки, публичные
каналы, API — в публичной версии есть полностью.
