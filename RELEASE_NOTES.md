## PocketChat 1.13.1

Правки по свежим отзывам после 1.13.0: текст на фото теперь ставится прямо в
точку клика, а «Стримы» больше не превращаются в стену без единой кнопки, если
на сервере нет плагина.

### 🖌️ Текст на фото — прямо на картинке, не плашкой

В редакторе фото инструмент «Текст» переделан под Телеграм-стиль: кликаете по
фото — туда и впечатывается текст (с тёмной обводкой, чтобы было видно на
любом фоне), а не отдельной полосой снизу. Цвет текста берётся из той же
палитры, что и у пера.

### 📺 Стримы — кнопки теперь всегда доступны

Раньше без серверного плагина экран «Стримы» показывал только сообщение
«нужен плагин» и вообще не рисовал кнопку «Начать стрим» — нажимать было
нечего. Теперь кнопка есть всегда; без плагина нажатие честно объясняет, что
без него стрим никто, кроме вас, не увидит, вместо молчаливого бездействия.

### 📦 В комплекте

- `pmchat-mod-1.13.1.jar` — клиентский мод (в папку `mods/`).
- `PocketChat-2.1.0.jar` — бесплатный серверный плагин (в папку `plugins/`,
  без изменений с 1.13.0). Нужен для медиа-релея, баланса, подарков и
  стримов/донатов (+ Vault и экономика вроде EssentialsX).

### 🔒 Чем отличается от приватной (secret) сборки

Публичная версия **не включает Pro-плагин** (`PocketChatPro`) и его премиум-
функцию:

- **Расшифровка голосовых сообщений в текст** — работает только с Pro-плагином,
  которого в публичной версии нет. В меню голосового пункт остаётся, но
  подписан «только Pro-плагин».

Всё остальное — профили, подарки, стримы, ЧС, темы, медиа-релей, звонки,
публичные каналы, API — в публичной версии есть полностью.
